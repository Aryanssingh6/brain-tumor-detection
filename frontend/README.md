# NeuroScan AI 🧠

AI-powered brain tumor detection using EfficientNet-B0, FastAPI, and Next.js.

## 🚀 Live Demo

- **Frontend:** https://brain-tumor-detection-ashy-three.vercel.app
- **Backend API:** https://brain-tumor-detection-production-aa5f.up.railway.app

## 🛠️ Tech Stack

- EfficientNet-B0 (PyTorch) — 95% accuracy on 4-class classification
- Grad-CAM explainability
- FastAPI backend
- Next.js frontend
